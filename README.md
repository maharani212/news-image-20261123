# World News — Monday 23 November 2026

A program that writes one image summing up the world's news of Monday 23 November 2026.

[![make.fun](https://make.fun/badge/news-image-20261123.svg)](https://make.fun/bounty/news-image-20261123)
[![rank](https://make.fun/badge/news-image-20261123/maharani212/news-image-20261123/rank.svg)](https://make.fun/bounty/news-image-20261123)
[![reward](https://make.fun/badge/news-image-20261123/maharani212/news-image-20261123/reward.svg)](https://make.fun/bounty/news-image-20261123)

Built for the [make.fun bounty "Sum up 23 November's world news in one image"](https://make.fun/bounty/news-image-20261123). The program writes a 1024×1024 front-page image of the day's news, deterministically, with no network.
